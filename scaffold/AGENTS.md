# Agent loop

1. Run `quoin blocks --missing --json`.
2. Draft each block for meaning.
3. Use a separate agent invocation for the style pass when the harness allows it.
4. Write `blocks/<id>.json` and `blocks/<id>.stylepass.json`.
5. Run `quoin check`.

Keep prose plain and concrete. Do not use em dashes or puffery. Quote the evidence line for each factual claim. Read the block aloud before calling it clean. Never change source prose.
